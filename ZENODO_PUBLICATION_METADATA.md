## Description (paste verbatim)

We determine D_{C6}(6) = 4096 for families of graphs on six labelled vertices such that the symmetric difference of any two distinct members is not *exactly* the edge set of a Hamiltonian six-cycle. This excludes exact C6 differences, not arbitrary differences containing a six-cycle. The 60 forbidden differences generate a nine-dimensional subspace; the full 15-bit problem decomposes into 64 isomorphic 512-vertex Cayley components. A 64-word linear independent-set construction and a 65-exclusion certificate using 90 integer Rayleigh inequalities, eleven symmetrized three-point moment equalities, and exact integer Farkas arithmetic establish the optimum. The machine-reconstructed positive contradiction gap is 65245054658776971334908126197187583410176. Two independent implementations and a direct-coset control check support the computation.
